# 0.7.3 分布统计自动上下界

下界、上界均可独立选择“手动输入”或“自动识别”。旧流程保留原有手动值；配置中的 `minimum: null` / `maximum: null` 表示对应边界自动识别。

自动识别读取直接上游完整范围内的有限值极值，包含前序时间编辑、ROI 和算法的实际输出；整段共用固定箱边界，试算、阶段检查与正式运行一致。首次识别需要扫描该范围，可取消；阶段检查复用有界缓存，上游数据或配置变化时失效。原始数据预览仍使用独立进程。

常量数据的自动边界向外扩展以建立非零宽度区间；全无效数据或与手动值冲突的范围明确报错。实际边界、识别范围及极值记录在输出映射中，NPY / CSV 和图形导出沿用该映射。

只运行分布统计专项测试及 `tools/smoke_distribution.py`，覆盖上下界独立切换、手动值恢复、自动范围下的逐帧预览与 SVG 导出。
