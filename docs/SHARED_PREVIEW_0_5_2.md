# 0.5.2 · 公共预览与算法流程预设

## 目标

视频预览独立于算法配置。通用处理与分幅关联使用同一数据画布、结果画布、帧读取队列、定位控件和播放循环；处理结果仍可单独查看、对比和导出。

模式选择移入模块流程列，作为流程预设入口。首次选择初始化对应模块和参数，再次切换恢复该预设的编辑草稿。通用预设为空白模块链，分幅预设为强度校准、固定配准、全源统计与二阶关联。所有模块仍来自同一目录，可增删、复制和排序。

## 实现边界

1. 中央预览不随预设切换重建。帧号、真实时间、显示窗宽和画布变换由公共预览持有；算法窗口、延迟与固定关联中心属于模块参数。
2. 单数据或单结果视窗占满可用区域，比例只用于并排查看。
3. 原始帧始终走同一读取、解码、绘制和播放路径。请求串行有界，快速定位合并到最后一次位置，过期响应不能覆盖新来源。
4. 中线、有效区、分析 ROI 和选点作为分幅模块的画布工具。配准和幅面预览在明确操作时更新；播放和普通定位不隐式重算配准、统计或关联。
5. 关联中心可独立设置，或明确采用当前预览帧。播放不暗中修改关联计算窗口；计算范围不足仍明确报错。
6. 分幅系数图、曲线、统计和逐帧输出进入公共结果视窗，保留参数、来源、导出和下一阶段输入功能。
7. 兼容旧项目的模式、模块实例、分幅参数及双列布局；旧分幅播放器位置不再覆盖公共来源定位。

## 操作变化

- 在右侧“模块流程”列选择“流程预设”；面板收起时先点击竖向标签展开。切换预设保留当前来源和预览位置，也可在播放中切换。
- 所有预设都使用中央底部的同一时间轴。选择“仅数据”或“仅结果”时，视窗铺满中央区域；“并排对比”仍可拖动分界线。
- 分幅初始化后，明确点击“按中线建议分幅 / 裁黑边”或选择幅面预览以更新几何。选取 ROI、选点和查看配准叠加使用同一数据画布。开始播放或普通定位会返回原始帧；派生预览按需更新。
- 在“范围 / ROI / 设备”设置关联中心帧；“采用当前预览帧”将当前精确帧号写入参数，“预览此帧”明确定位到指定中心。普通播放不改变该参数。
- 统计图、系数图和延迟曲线均在公共结果视窗查看；切换流程预设不清除当前结果，结果时间及 τ 控件只调整结果。

## 验证

102 项自动测试通过。真实浏览器检查单窗铺满、播放中切换预设、同一画布和请求路径、快速定位与末帧停止、原图变换及 ROI 保留、分幅 ROI 键盘微调、结果缩放、试算与正式结果、曲线导出、项目恢复及 1440 / 1100 / 960 宽度布局。

两种预设的播放检查均最多一个在途帧请求，未触发几何计算；手动选择派生预览才发出几何请求。真实 CINE 样例包含 370801 帧，验证保存值、真实时间、触发帧、ROI 处理和 TIFF / CSV 导出，原文件大小与修改时间未变化。该样例未执行全序列背景扫描；吞吐随数据与机器性能变化。
