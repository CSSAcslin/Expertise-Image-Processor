# 0.7.1 交互修复

本轮围绕预览可操作性与处理边界修复五项问题，使用既有模块数值实现。

## 轴标识

流程卡片显示完整主输出轴：时间图像 TYX、双路图像 TPYX、点时间信号 T、有符号延迟信号 Q 等。静态 N:1 记录简写为 YX、PYX 或“标量”，不伪造时间轴。旁路另列实际轴；悬浮查看输入、主输出及旁路的完整尺寸。T:1 仍是一个时间样本，只有明确截面或静态统计才移除 T。

## 运行到当前模块

选中实例后，运行条的“运行到当前模块”从来源执行至该实例，包含此实例。只校验并执行这个前缀，后序不完整或不兼容节点不会阻断前缀运行。停用实例继续遵循透传规则。结果照常保存完整数组、参数、版本与来源，运行记录的 execution_scope 标明终点及原流程长度；原始编排保留。

“试算”和“运行流程”仍覆盖完整流程。运行到当前模块属于正式处理，会执行此前的完整统计、所选范围和截流交付，并进入正式任务队列。

## 交互检查与画布工具

输入 / 输出检查通过 `/api/modules/inspect` 使用独立进程，复用 SequenceEngine。原始解码、交互检查、正式任务分开；检查不新增任务记录，不导出数据集。空间检查读取当前输出样本并显示独立坐标，信号检查显示当前样本的标量或分量。

工具栏提供 ROI 与取点入口，未选中对应实例时在当前节点之后添加模块；坐标属于该模块的直接上游。新 ROI 进入绘制状态，已有 ROI 可调整。检查器仍提供修改 ROI、点、线和配准工具。

同一时刻最多一个检查进程。新请求可替换旧检查，“取消检查”结束该进程；改变来源、参数或检查样本后丢弃过期响应。检查最长两分钟，单样本返回上限 128 MiB，信号最多显示 4096 分量。若前序确实需要全序列统计或普通视频索引，仍计算真实依赖，不跳过或近似；原始播放和定位保持独立。

## 结果与任务记录

点击“数据／并排／结果”会恢复对应视窗，隐藏、浮动和刷新后的布局不再使所选视图保持空白。结果按自身样本浏览，显示真实来源帧与时间；原始帧没有对应输出时不强制清空整个结果。结果导航保持当前视图，数据与结果各自缩放和平移。

任务详情只显示一份可折叠日志。已终止任务的重复取消请求不再把状态改回“取消中”。

## 验证

- Python 回归 152 项通过，包含前缀数值与来源、标量 T、静态 YX、编辑后坐标、正式任务与检查并发、检查替换 / 取消，以及终止状态竞态。
- `tools/smoke_gui_fixes.py` 使用隔离服务和独立浏览器，检查画布实际像素，覆盖结果隐藏 / 浮动 / 刷新恢复、视图保持、无效后序节点的前缀运行、正式任务运行中的工具栏取点 / ROI、信号检查及日志折叠。
- `tools/smoke_workbench.py` 保留完整模块工作台、导出、参数引用、R/B/Q 与大小窗口回归。
