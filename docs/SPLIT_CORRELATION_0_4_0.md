# 分幅强度关联 0.4.0

本版本提供独立 Web 工作模式及完整 CPU 路径：双幅预览、固定配准、完整全源统计、正负延迟系数图、固定中心的点 / ROI 曲线、导出与结果继续处理。原文件只读，显示映射不参与科学计算。

## 开始使用

1. 启动 `start.cmd`，在顶部“模式”选择“分幅强度关联”。选择灰度 CINE 或带精确帧索引的图像 / TIFF 序列；普通视频需先导出灰度帧序列。
2. **分幅与配准**：原图上绘制两点中线，分别修改左右有效矩形；支持拖动、边角缩放及整数坐标。黑边阈值生成建议，需人工修正。右路镜像、采样偏移可调整；“自动平移建议”给出 FFT 相位配准偏移与峰值 / RMS。应用后查看叠加，点击“接受当前标定”。该参考帧的实际身份与固定映射写入运行记录。
3. **预处理检查**：默认输入为“保存码值”。只有已确认相机线性响应时选择“线性强度”，或提供单调的一维 `.npy` / JSON 线性化 LUT。暗场偏置使用校准后单位，饱和阈值使用输入码值。计算全源统计，检查两路均值、方差和当前正负涨落。
4. **关联试算**：设置奇数平均窗口 W、时间步长 S、带符号帧延迟 q 的上下限 / 步长或稀疏列表；选择分析范围。中心帧从 1 开始显示，点 / ROI 坐标从 0 开始，均在裁黑边后的左幅参考网格上。可选最多 32 个点和一个 ROI；ROI 可拖动修改或输入精确坐标。保留的点必须位于 ROI 内。
5. 点击“固定帧曲线”独立扫描延迟，或“当前窗口试算”查看该中心的所有指定延迟图。两者都使用完整全源统计，首次运行会读取整个来源；更改 W、S、q 或分析 ROI 可复用统计。
6. “运行时间序列”保存完整有效中心范围的系数图；大任务先用“检查整段范围与容量”核对数量和空间。后台任务可取消，预览仍可继续。
7. **结果**：时间与延迟独立导航，播放固定 τ。系数图使用固定色标，紫色表示无效；鼠标可查询实际数值。曲线显示 g²=1 和 q=0 基准、实际时间 / 帧延迟横轴及逐点读数。刷新及项目保存保留结果位置。
8. 下载 TIFF 切片、窗口 CSV、曲线 CSV / PNG / SVG / JSON、运行 JSON。点击“当前 τ 序列作为下一阶段输入”回到通用处理，来源链保留窗口、映射、延迟和原始来源。已有输出可通过 `run.json` 重开；项目同时保存来源、模式草稿和完成结果引用。

## 数值约定

对左中心 c、W=2h+1 和帧延迟 q：

\[
g^{(2)}(p,c,q)=\frac{\langle J_L(p,i)J_R(p,i+q)\rangle_W}
{\langle J_L(p,i)\rangle_W\langle J_R(p,i+q)\rangle_W}.
\]

q<0 取较早右路帧，q>0 取较晚右路帧，q=0 使用同一采集帧。每个 q 独立配对计算，不由正值曲线翻转生成负值。实际时差来自完整窗口中的逐帧时间差，记录均值 / 最小值 / 最大值；缺失时间只保留帧延迟，不用平均帧率补造秒数。

强度处理顺序为传感器码值 → 可选 LUT → 各路暗场偏置 → 固定空间映射 → 固定尺度。默认最近邻使用 `floor(x+0.5)`；双线性亚像素会混合传感器像素，必须显式选择。仅使用有采样支持的共同有效区，不用越界边缘填充参与计算。

全源平均 B 是每个对应像素在**全部输入帧**上的时间平均，包含静态对象信息；它与单独测量的暗场不同。各路尺度 s 是全源、全部有效像素的时间涨落 RMS，一个幅面一个常量；不缩放选项取 s=1。保存校准强度均值 / 方差和有效计数，计算时使用 J=I/s 以及 δ=J−B/s，保留负涨落，计算：

\[
g^{(2)}=1+\frac{\langle\delta_L\delta_R\rangle_W-
\langle\delta_L\rangle_W\langle\delta_R\rangle_W}
{(B_L/s_L+\langle\delta_L\rangle_W)(B_R/s_R+\langle\delta_R\rangle_W)}.
\]

这是标准公式的代数重写，窗口内残差均值也被计算。两路固定乘性尺度会约去；暗场偏置、插值和非线性 LUT 的影响不会约去。两路均值和乘积使用同一联合有效样本集合。NaN / Inf、饱和排除、支持域以外、样本不足或缩放后强度均值过小均标为无效，不靠添加 ε 生成系数。g² 不裁剪到 −1～1。

ROI 曲线有两种估计：

| 选择 | 计算 | 空间支持 |
| --- | --- | --- |
| 逐像素 g² 空间平均 | 对各对应像素计算 g²，再等权平均 | 全部所选 q 上都有有效系数的共同像素集合 |
| 区域总强度 g² | 每帧先对区域求和，再计算两路总强度的 g² | 所有配对窗口内两路均有效的固定共同像素集合 |

导出标明估计方式、像素数、有效样本范围、固定中心及每个窗口。两种曲线一般不相等。

对分析范围 `[a,b)`，D₋=max(0,−min q)，D₊=max(0,max q)：完整公共中心从 a+h+D₋ 到 b−1−h−D₊，按 S 取样。头尾除了 h，还需舍弃相应延迟覆盖长度；不补零、不缩短窗口、不环绕数据。

## 输出与资源

| 文件 | 内容 |
| --- | --- |
| `run.json` | 来源指纹、版本、固定几何、参数、数值语义、设备、状态及来源链 |
| `g2.npy` / `counts.npy` | TQYX 磁盘映射系数图与 uint32 联合有效计数，仅图任务生成 |
| `mean.npy` / `variance.npy` / `mean_counts.npy` | 两路完整全源的校准强度均值、时间方差和有效计数 |
| `timestamps.npy` / `source_numbers.npy` | 原始帧时间 / 触发时间及采集源帧号 |
| `windows.csv` | 输出时间 / 延迟到中心、左右窗口及实际时差的映射 |
| `curves.json` / `.csv` / `.png` / `.svg` | 固定中心的点 / ROI 数值、窗口、配置与科学绘图 |
| `linearization_lut.npy` | 使用 LUT 时保存运行校准副本，并记录哈希 |
| `lag_*.eip.json` | 选定延迟作为下一处理阶段输入的本地引用 |

界面默认系数图 **float64**，便于保存接近 1 的微弱差值；float32 占用更小。两种保存方式均以 float64 累计，曲线使用 float64 数值。TIFF 切片保留所选输出精度，超出该精度有限范围的值标为无效。

N 帧、共同区域 H×V、K 个有效中心和 Q 个延迟时，系数与计数的逻辑大小为 `K×Q×H×V×(系数字节数+4)`。当前 `.npy` 不压缩 / 分片，需足够磁盘空间；独立曲线任务不生成四维系数数组。输出在 `.partial` 中生成，完成后才发布；失败 / 取消记录保留，不能作为正式下一阶段输入。

工作数组、读取缓存、转换帧缓存和延迟批次根据工作内存预算安排；W 大于缓存时重新按需读取出窗帧，不一次装入整个窗口。预算不是进程 RSS 上限，Python / 绘图库、解码器与 CINE 元信息索引仍有开销；CINE 索引另受现有 128 MiB 上限约束。历史统计位于 `.eip-cache/split`，依据来源修订、几何、校准、LUT 哈希及版本复用；未完成缓存不复用。

CPU 始终可用。Auto 仅在任务启动时检测可用 CuPy / CUDA、显存和 float64 自检；失败则回退 CPU 并记录原因。显式 GPU 不可用时给出错误；计算中异常不会暗中重跑。当前机器未验证真实 GPU 加速或 CPU / GPU 容差。

## 模块扩展与当前边界

代码位于 `src/eip/modes/split_correlation/`：`config`、`geometry`、`photometry`、`correlation`、`backend`、`storage`、`runner` 分开。`RegistrationMethod` 返回固定平移建议，`CorrelationEstimator` 约定增量配对与系数 / 计数结果。当前是代码级扩展；新几何模型需同时扩展映射和支持域，新的关联公式需独立参数与数值验证，不直接套用通用逐帧插件。Web 服务和模式控制器分别位于 `web/split.py`、`web/static/split.js`。

首版只支持固定平移及显式镜像。自动建议需人工检查，不能保证未知局部畸变的每个像素匹配；仿射、非刚性、特征控制点和机器学习配准待验证。CINE 保存码值的光强线性关系需要相机校准资料；显示伽马不用于反推强度。分数帧 τ、时间—延迟概览、多个 ROI 管理、压缩存储及断点续算尚未实现。
