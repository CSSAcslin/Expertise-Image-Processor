# 0.6.0 模块运算清单与空间、时间契约

本文是 0.6.0 实现使用的运算规格。先对照 0.5.2 盘点 11 个现有模块，再补入 5 个空间 / 时间模块，共 16 个内置模块。当前完整参数表由代码生成，见 [MODULE_INVENTORY_CURRENT.md](MODULE_INVENTORY_CURRENT.md)。数据预览始终独立于流程计算。空间裁剪、归约和时间编辑是实际改变下游数据的模块；执行设置只管理设备、精度、资源及启停，不能暗中改变 ROI 或时间范围。

## 数组和样本

T 是当前时间轴的样本数，Y/X 是当前空间尺寸，C 是明确的 RGB/RGBA 分量，P 是左右两路，Q 是有符号延迟列表。P 与 C 不混用。二维灰度序列为 `T×Y×X`，彩色序列为 `T×Y×X×C`，对齐双路为 `T×P×Y×X`，区域归约后为 `T` 或 `T×P`；彩色只对 Y/X 归约时保留 C。

每个阶段携带：数组轴、尺寸、样本数、数值含义、位深、当前坐标到来源坐标的映射、时间到来源样本的映射、无效值规则和上游实例指纹。来源帧未知时保持未知。合帧后的样本不得冒称某一个采集帧。

模块停用时输入原样通过。连接校验基于当前上游输出，不能只按算法名称或工作模式决定兼容性。界面显示每一步实际的输入 / 输出形状及不兼容原因。

## 模块清单

下表中所有位置均相对于该模块的直接输入。新模块的参数与旧任务级参数不能同时拥有同一含义。

| 模块 | 公式 / 算法 | 参数 | 输入 → 输出 | 约束与无效值 |
|---|---|---|---|---|
| 时间裁剪 `time_crop` | 保留 `[first−1,last)` 的样本，尾样本包含；或保留 start≤真实时间<end | unit=samples/seconds；first≥1；last 留空至末尾；start/end 秒 | T×… → Tc×… | 仅流程起点，可有一个；不能在后续模块重复设置运行范围；普通视频实际解码建立临时索引，不能由帧率推算 |
| 空间 ROI `spatial_roi`：保留像素 | `B_t=A_t[y:y+h,x:x+w]` | x,y,w,h；留空宽高到当前边界；mode=pixels | T×(P)×Y×X×(C) → T×(P)×h×w×(C) | 整数矩形，不复制全帧输出；下游坐标从 0 起，另存来源原点；左右路用同一参考区域 |
| 空间 ROI：均值 / 总和 | `s_t=Σ_valid A_t/n_valid` 或 `Σ_valid A_t` | mode=mean/sum；validity=joint/independent | 灰度 T×(P)×Y×X → T×(P)；彩色保留 C | 只归约空间轴；全无效输出 NaN。双路默认在每个样本内取共同有效像素，独立集合须显式选择；支持集合仍可能随时间变化。下游不能再接空间滤波或空间 ROI |
| 空间 ROI：分位值 | 将区域内有限值排序，`u=(n−1)q`，在 floor(u)、ceil(u) 间线性插值 | mode=quantile；q∈[0,1] | 同空间均值 | q=0.5 为中位数；非线性操作会改变涨落和 g²，明确记录 |
| 时间取间隔 `time_sample` | `B_j=A_(offset+j·step)` | step≥1；offset≥0 | T×… → Ts×… | 不插值、不合帧；保留真实采样时间，不能据平均帧率伪造 |
| 时间加窗 `time_smooth` | `B_j=Σ_valid A_(j+k)/n_valid`，k=0…W−1；或同窗分位值 | 奇数 W；mean/quantile；q | T×… → (T−W+1)×… | valid 边界，不补帧；输出对应窗口中心样本时间；空间与双路维度不归约；分位值需检查窗口内存 |
| 时间合帧 `time_bin` | 每 B 个连续样本逐元素取均值或总和 | size≥1；mean/sum | T×… → floor(T/B)×… | 尾部不满组舍弃并记录；时间为组内已知真实时间均值，任一未知则未知；不赋予虚假的采集帧号 |
| 强度线性变换 `intensity` | `round_clip_dtype(gain·A+offset)`；浮点保持浮点 | gain、offset | 当前数值数组 → 同轴同尺寸 | 整数四舍五入并限幅；不适合需要保持细微涨落的整数增益流程时可选 affine |
| 浮点仿射 `affine` | `gain·A+offset` | gain、offset | 图像、双路、标量/向量、系数 → 同形状 float | 不量化、不限幅；溢出转 NaN |
| 均值滤波 `box_blur` | `(2r+1)²` 空间均值，反射边界 | r≥1 | 含 Y/X 的矩阵 → 同形状 | 只处理空间；要求有限像素；不得把时间标量伪装成 1×1 图像 |
| 高斯滤波 `gaussian` | 分离核 `K_k∝exp(−k²/2σ²)`，逐轴归一有效权重 | σ>0；r≥1 | 含 Y/X 的矩阵 → 同形状 float | 边界复制；原无效位置保持无效；Q 轴、T 轴不作为空间轴 |
| 阈值 `threshold` | `1[A≥θ]`；彩色先对前三颜色分量取均值 | θ | 数值数组 → 同空间尺寸标签；彩色去 C | 标签含义显式；标签不可作为光强进入统计 / g² |
| 固定强度曲线 `curve` | x=A/M；identity、x、√x、x²、x^γ、ln(1+9x)/ln10 | curve、M>0、γ>0 | 任意数值数组 → 同形状 float | 固定尺度；不逐帧拉伸；负值的非法定义域输出 NaN |
| 强度校准 `calibration` | 保存码值经固定曲线或 LUT，再减对应暗场；饱和 / 非有限值置 NaN | curve、M、γ、LUT 路径、暗场、饱和阈值、强度语义 | 单幅 / 双路强度 → 同形状强度 | 配准前按明确中线区分两路暗场；LUT 文件内容留快照；不得使用显示 LUT 作为输入校准 |
| 双幅配准 `alignment` | 固定左右矩形、镜像与平移；右路在左路参考坐标上最近邻 / 双线性采样 | 中线、左右有效区、dx/dy、镜像、插值 | 灰度单幅 T×Y×X → T×P×h×w | 自动建议为相位相关平移，人工检查接受；仅公共有效区；裁剪后的输入需按新坐标重新设置参数 |
| 选择幅面 `select_channel` | B=L 或 B=R | left/right | T×P×… → T×… | 保留空间 / 时间 / 来源；不能接收单幅输入 |
| 全输入统计 `statistics` | 逐元素 Welford：μ=ΣI/n，σ²=Σ(I−μ)²/n；每路固定 RMS `sqrt(ΣM2/Σn)` | none/fixed_rms | 强度序列 → 相同序列 + 均值、方差、计数、尺度 | 统计的是此节点直接输入的全部时间范围，包含已执行的时间 / 空间编辑；全无效为 NaN；改变强度的后续模块会使旧统计失效，须重新统计 |
| 二阶互关联 `correlation`：固定 τ | `g²_q(c)=⟨L_iR_(i+q)⟩/(⟨L_i⟩⟨R_(i+q)⟩)`；i∈中心 c 的 W 窗口 | W 奇数、q 可负/零/正、中心或输出步长 S、min_mean、min_samples | 对齐矩阵双路 → T'×Y×X；标量双路 → T' | 左右同一有效样本集合；完整窗口；分母使用真实强度均值，不能用去背景残差均值；均值过小或样本不足输出 NaN |
| 二阶互关联：固定中心 τ 曲线 | 同上，固定 c 扫描 q，不能假设对称 | c、W、有符号 τ 列表或范围/步长 | 双路区域矩阵 → Q×Y×X；双路标量 → Q | 区域矩阵可在此节点之后加空间均值以得到“逐像素 g² 空间平均”；关联之前做区域均值 / 总和则为“区域信号的 g²”，两者不同 |
| 自定义逐帧算法 | 插件 prepare/process/close | 注册描述中的独立参数 | 已声明的 YX / YXC → 声明的输出 | 现有插件要求保留空间尺寸；不默认宣称支持标量、时序或改变形状。扩展须声明并实现适配，机器学习亦同 |

## 组合的科学含义

1. `时间裁剪 → 配准 → ROI 保留像素 → 统计 → g² 固定 τ`：只输出选定区域的系数矩阵。
2. `时间裁剪 → 配准 → ROI 均值 → 统计 → g² 扫描 τ`：每路先变成一个时间标量，再计算区域信号的关联曲线。
3. `时间裁剪 → 配准 → g² 扫描 τ → ROI 均值`：先计算每个像素的关联，再对系数做空间平均。与第 2 条不能互换。
4. `时间裁剪 → ROI 保留像素 → 空间高斯` 与 `时间裁剪 → 空间高斯 → ROI 保留像素` 的边界上下文不同，必须按顺序真实执行。
5. 用户已确认：`时间裁剪 → 时间合帧 → 配准 → g²` 的 W、τ 和输出步长均按编辑后序列计数；同时保留原始贡献样本及逐对代表时间差。时间编辑放在关联之后时，仅编辑结果，不回改此前的 W/τ。固定中心 τ 曲线的 Q 轴不是时间轴，不允许误接时间编辑。

## 界面与兼容

- 每个实例仅呈现该算法参数、输入输出契约和执行设置。删除共享的“运行范围 / ROI”附加面板；输出目录、名称和正式运行按钮仍属于工作台。
- 画布 ROI 操作编辑明确选中的空间模块实例，预览其输入坐标；不能修改不可见的任务级 ROI。查看某步输入 / 输出是显式试算，普通播放不执行流程。
- 时间裁剪固定在开头，后续时间操作可以自由排列；空间 ROI 可重复、移动、停用和删除，标量输出后的非法连接明确阻止。
- 旧任务末尾 ROI 迁移为链末的空间裁剪模块，保留原有滤波上下文；旧运行范围迁移到开头。旧分幅关联 ROI 迁移到关联之前；区域总强度估计迁移为 ROI 求和后再关联，逐像素系数空间平均迁移为关联之后归约。重构后统计使用裁剪后的上游范围；旧总强度的窗口共同掩码与新 ROI 的逐样本共同掩码不同，迁移草稿必须提示检查。旧多个点的草稿提示重新指定区域，不能把多个点悄悄归并为一块 ROI。
- 旧已完成结果按原记录读取，不重解释历史数据。迁移草稿需保存新的契约版本和模块实例顺序。

## 验证标准

手算小数组验证裁剪次序、空间均值 / 总和 / 分位值、时间抽样 / 加窗 / 合帧、标量与矩阵 g² 差异、正负 τ、NaN / 饱和 / 边界。每次正式运行保存各节点的契约、实际样本映射和完整参数。浏览器验证两个预设共用原始预览、实例 ROI 编辑、标量曲线与矩阵结果、错误连接、旧草稿迁移和导出。

## 已实现的执行与边界

- `module_contracts.py` 编译每步输入输出轴、形状、含义及依赖；`sequence_engine.py` 按列表执行，单幅、双路、标量和颜色向量共用执行器。CPU 完整可用，关联可选 GPU；重计算在后台进程。
- 试算与正式运行共用实现。没有关联的试算检查一个指定的编辑后输出样本；固定 τ 试算使用关联模块的中心；关联之后有时间窗时保留所需上游上下文。τ 扫描试算保留完整 Q。
- 单幅校准使用不同左右暗场时，中线必须来自明确的后续配准实例。截断流程的阶段检查保存 `preview_dependencies`，仅读取该中线，不执行这些后续模块；依赖参与指纹。正式运行按完整流程执行，不能使用阶段依赖替代模块。
- 输出 `values.npy` 保留真实形状，`measurements.csv` 保留全部信号数值 / 矩阵统计，`references.jsonl` 与索引保留时间、贡献区间及真实延迟。合帧不伪造采集帧号；source_span 为来源包络，精确取样由上游模块顺序及参数重建。
- 均值、方差、有效计数、固定尺度及 LUT 内容单独保存；不复用未经相同上游指纹校验的跨任务统计。当前任务内按需缓存有界，重复统计保存数组及工作数组检查预算。
- 矩阵预览与标量 / 向量曲线使用独立结果窗口。曲线显示及静态图有限抽样并标明，NPY/CSV 完整保存。原始播放器不隐式执行流程。
- 旧执行器只负责旧协议兼容；新 Web 流程统一使用契约3。插件目前仅声明逐帧 YX/YXC，不能假装支持标量、时序或任意形状；实际输出 dtype 在运行确定并保留。
- 普通视频的临时解码索引与帧引用写入磁盘，引用缓存最多256项。真实时间选择保存连续区间，最多4096段；加窗 / 合帧 / 延迟的时间统计逐项累加，不在内存保留整段帧引用。标签或 g² 经均值、求和等数值编辑后标为派生结果，不能继续冒称原始标签或标准逐像素 g²。
