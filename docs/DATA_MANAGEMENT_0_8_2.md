# 0.8.2：底部数据管理

输入来源与处理结果整合在底部“数据管理”面板。两组标题一直可见，数量分别统计；点击组标题上下展开 / 收起，拖动面板上边缘或使用方向键调整高度。顶部收起按钮同时折叠两组；折叠和高度随草稿及项目保存，旧布局自动迁移。

## 操作

| 控件 | 行为 |
| --- | --- |
| 输入 / 结果行 | 预览对应数据，共用已有播放器与画布 |
| 两组搜索框 | 分别查找来源或结果 |
| 行复选框 / 组内全选 | 独立批选，不改变另一组，也不切换当前预览 |
| 输入区播放图标 | 使用当前模块流程正式运行所选输入 |
| 输入区垃圾桶 | 移除所选来源引用；正在被任务使用的项保留并报告原因 |
| 结果区下载图标 | 一次下载多个完整运行包，各自保留目录、运行记录和数值 |
| 结果区垃圾桶 | 确认名单后批量移除工作区记录，保留文件 |
| 行内或所选结果工具条 | 单个输出预览、复用、导出、参数、改名及逐项清理 |

已有结果不再阻止移除输入引用。来源文件、已保存输出和派生输入的来源快照保持可用；源帧、坐标、时间与运行参数仍可追溯。任务仍在执行或排队时，该来源的移除按钮说明占用原因；批量移除逐项报告成功与失败。

结果文件的永久清理继续使用逐项确认、完整路径预览和引用检查。批量操作只移除引用，不删除原始文件或结果文件。仍被派生来源、后续任务或下载引用的文件不可永久清理，界面列出相关名称。

小窗口压缩控制条并约束流程 / 任务 / 管理面板高度，保留实际结果图像。最大化预览或模块窗口也为底部管理面板留出空间。展开、选中或折叠数据管理不会隐式运行算法。

.\.venv\Scripts\python.exe tools\smoke_result_interaction_0_8_1.py
.\.venv\Scripts\python.exe -m pytest -q
~~~
