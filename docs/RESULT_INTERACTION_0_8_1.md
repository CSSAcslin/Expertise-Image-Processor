# 0.8.1：结果管理交互调整

结果管理改为工作台左侧的 **结果** 页，与数据、模块并列。结果视窗右上角使用同一叠层图标进入。取消阻挡画布的管理弹窗及每行长操作文字，选中结果时直接使用公共结果画布预览。

## 常用操作

| 入口 | 操作 |
| --- | --- |
| 结果行 / ↑ ↓ / Enter | 选中并预览；重复打开当前结果保留样本位置 |
| 搜索 / 全部、正式、试算 | 查找与筛选；Escape 清空搜索 |
| 铅笔 / Enter / Escape | 就地改名、保存、取消编辑 |
| 眼睛 | 显示所选输出；共用已有结果视窗和播放状态 |
| 箭头进入数据 | 作为下一阶段输入；保留类型与来源，清空流程可撤销 |
| 下载 | 导出整个运行包；行内也提供快捷下载 |
| 下载旁的箭头 | 导出所选主输出或附加输出的 NPY、CSV、映射、记录或适用图像 |
| 信息 | 按需查看完整参数与来源 |
| 垃圾桶 | 选择仅移除记录或永久清理文件 |
| 页眉文件夹 | 通过文件浏览器或路径打开历史运行记录 |

名称、状态、输出选择与图标工具条保留在结果列表下方；完整路径和来源默认折叠。图标提供悬停提示与可访问名称，禁用操作说明原因；试算的“作为输入”保持禁用。导出时显示忙碌状态，文件使用现有直接下载协议。

删除确认显示名称与文件体量，默认保留磁盘文件。仍被引用时禁用删除文件；选择永久删除会展开完整目标路径并明确显示不可撤销操作，依赖检查沿用 0.8.0。无完整任务记录的旧结果引用继续支持预览、来源查询、复用与移除引用。

小窗口浏览结果时暂时收起覆盖画布的响应式检查器；返回数据或模块页后恢复。无需新播放器、独立预览缓存或额外算法计算。
