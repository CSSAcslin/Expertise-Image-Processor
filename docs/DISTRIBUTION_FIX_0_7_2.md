# 0.7.2 分布统计直方图修复

- 分布统计的“检查输出”读取模块的频数端口；旁路设置下不再误显示透传的 TYX 图像。
- 输出为每个上游样本一组固定箱计数，保留 T / Q / N 序列轴及 B 箱轴。视频通常为 TB，不再保留 YX 空间轴。

- PNG / SVG 导出为首个已保存样本的直方图，菜单及图题明确范围；NPY / CSV 保留完整频数序列。
