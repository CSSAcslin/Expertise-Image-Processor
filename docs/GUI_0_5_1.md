# 0.5.1 · 可调工作台面板

本版围绕视频预览和处理配置调整 Web 工作台。通用模式、分幅模式使用相同的面板交互；算法模块、公式、数据含义和结果格式沿用 0.5.0。

## 右侧两个独立列面板

- 右侧并排两列，左列“模块流程”：添加、选择、复制、删除、启停和排序模块。
- 右列“参数设置”：编辑选中的模块实例。通用算法的参数也统一放在这里；分幅校准、配准、统计与关联继续提供对应的专用操作。
- 点击列标题向右收起为竖排窄标签，点击标签向左展开；各列独立滚动。收起释放的宽度让给预览，另一列保持宽度，再次展开恢复原有列宽。两列都收起时保留两个标签供随时展开。
- 点击流程中的模块卡片或“编辑此模块参数”，会选中该实例并展开参数面板。复制实例仍保持独立参数；删除当前实例后显示剩余实例，空流程显示选择提示。
- 处理范围、ROI、设备和导出是工作台设置，保留在参数面板中的折叠区。分幅预览上方仍可直接进入“范围 / ROI / 设备”和“结果 / 导出”。

## 拖动分隔边界

可调边界包括：数据来源与预览、预览与右侧两列、模块流程列与参数设置列之间、任务记录上边界，以及数据 / 结果双视窗之间的边界。

拖动细分隔条调整；鼠标经过时分隔条高亮。双击恢复该边界的默认尺寸。分隔条也可通过 Tab 聚焦，方向键微调，Home 恢复默认尺寸；栏宽与任务高度支持 Shift 加方向键加大调整步幅。

拖动预览右边界调整两列的总宽度；拖动列间边界重新分配两列宽度。收起一列时仍可拖动外侧边界调整展开列，收起列保留自己的展开宽度。两列均收起时总宽度固定为两个窄标签，通用模式的运行页脚在展开任一列后恢复。

两列使用并排布局，有独立列宽和展开状态。尺寸有上下限，小窗口自动限制侧栏宽度和任务区高度，给预览保留空间；密集的预览工具区和结果控制区可内部滚动，帧定位控件优先保留。需要更大画布时，可收起来源或处理面板、选择仅数据 / 仅结果，或使用“专注预览”。

## 保存和恢复

浏览器刷新与项目 JSON 保存：来源栏宽、各模式的两个展开列宽与收起状态、任务高度与收起状态、双视窗比例、当前选中的模块实例。通用和分幅模式分别保存右侧列设置。

顶部“重置布局”恢复默认列宽和展开状态。旧项目没有这些设置时使用默认布局；先前上下堆叠面板的总宽度与高度比例不套用到列宽，旧的收起状态继续保留。浏览器缩小时只限制当前显示尺寸，放大后恢复之前保存的尺寸偏好。

这些操作只修改视图偏好，不修改帧定位、ROI、算法参数或原始数据；画布按当前窗口重绘，保留用户的缩放和平移状态。

## 验证

`tools/smoke_layout.py` 使用独立临时工作区和真实浏览器验证：两列并排、七类分隔条拖动、键盘调整、列独立水平收起及空间回收、再次展开恢复列宽、模块实例参数与选中状态、刷新与项目恢复、旧布局迁移、模式切换，以及 1440 / 1100 / 960 像素窗口内的布局。

原有通用与分幅浏览器流程继续检查 ROI 编辑、数值试算、正式处理、来源串联和图像 / 曲线导出；真实 CINE 用于检查帧定位及分幅模式原始预览。
