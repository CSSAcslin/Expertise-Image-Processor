# 0.7.4 模块整理与统计

本次整理服务于“预览上游数据 → 配置模块 → 检查统计 / 算法结果 → 导出或继续处理”。新模块库提供 25 个入口，旧记录另保留 9 个兼容定义；统一目录见 [模块清单](MODULE_INVENTORY_CURRENT.md)。

## 入口与分类

- 空间均值平滑、高斯平滑合并为修饰模块“空间平滑”，在参数中选择类型；σ 仅在高斯类型中显示。
- 定类型与浮点增益 / 偏置合并为修饰模块“增益 / 偏置”。实例执行覆盖的“精度”选择保留输入类型、float32 或 float64；浮点输出不会先经历整数舍入。
- 固定尺度强度映射、固定尺度归一属于修饰模块。
- 参数传递、点信号提取、直线截面提取、按轴截面属于中间模块；分类不会绕过真实轴和数据类型校验。
- “添加模块”旁新增“清空模块”，清空全部实例并支持撤销 / 重做与刷新后恢复。来源、历史任务和结果仍可查看。
- 两个 g² 模板不再添加序列统计。新模块库也不再提供该入口。

## 两种统计

| 模块 / 范围 | 归约内容 | 示例 |
| --- | --- | --- |
| 时序统计 | 每个样本的空间 / 分量轴，保留样本轴及 P/C | TYX → T，TPYX → TP，QYX → Q |
| 全域统计 · 全部数据（默认） | 所有样本与分量 | TYX → N:1 的标量 |
| 全域统计 · 样本轴 | 仅直接上游样本轴 | TYX → N:1 × Y × X；逐像素时间均值 / 方差 |
| 全域统计 · 样本与空间轴 | 样本及除 P/C 外的分量 | TPYX → N:1 × P |

“时序统计”是原区域归约的新入口，形成逐样本统计信号；不表示沿时间滑窗平滑。Q 保持延迟含义，不伪装成 T。全域统计生成静态 N 记录，采集帧号和时间为空，贡献范围及所选统计轴随结果保存。

统计量包括 **均值、总和、最小值、最大值、方差、标准差、分位值、有效值数**。min/max 直接求极值；方差为总体方差（ddof=0）。只统计有限值；空集合的计数为0，其余为 NaN。双路共同 / 独立有效值规则明确可选。分位值参数仅在选中分位值时显示。

两种统计均可替换主路或产生旁路。全域统计的 `value`（所选统计值）和 `count`（有限值数）可通过参数传递或参数旁“引用”接入后序；标量参数不能绑定矩阵，固定尺度可接兼容的 P 向量。

全域统计读取**完整直接上游**，包括前序时间范围、抽样、ROI 和算法结果；关联后的全域统计在试算时也不会只读取一个关联输出。均值 / 方差 / 极值等流式累积，精确分位值使用临时磁盘上的原地选择，不近似抽样。磁盘不足明确报错，取消或完成后清理临时缓存。长范围统计在计算进程执行，原始预览保持独立。

## 旧流程

迁移只创建可编辑配置副本，保留实例 ID、参数引用及实际类型。旧浮点增益 / 高斯默认输出 float64，迁移后显式保留该精度。原定类型增益 / 均值平滑若另有浮点覆盖，仍保留旧兼容计算，以免把“先整数舍入再转浮点”改成不同结果。

旧序列统计的逐像素均值 / 方差 / 计数可由全域统计的“样本轴”范围替代。旧固定涨落 RMS 是逐位置时间方差的加权汇总，与“全部数据”的总体标准差不同；已有流程及引用继续使用兼容节点，不进行含义不同的自动替换。已完成的历史结果不重算。

## 本轮验证

仅运行模块整理专项数值测试、受影响的模块兼容测试（48 项通过），以及 `tools/smoke_module_revision_0_7_4.py` 浏览器验证。覆盖合并后的精度、统计范围与 NaN 支持、精确分位值、参数传递、g² 后全上游试算、清空 / 撤销 / 重做 / 刷新、两个模板、结果预览与 NPY / CSV 导出。浏览器无未捕获脚本错误，桌面与小窗口截图及报告位于 `.test-output/module-revision-1791894632`。
