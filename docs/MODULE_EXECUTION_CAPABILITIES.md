# 全部模块执行能力与优化边界

日期：2026-10-29。范围：当前目录的36个内置模块，包含保留兼容的旧模块，以及通过统一契约注册的插件。

处理流继续由模块实例定义。执行器可以减少请求范围、复用静态索引、按块交接或批量调度，但必须保留直接上游语义、实例精度、作用通道、真实时间和贡献来源。下表记录每个模块可以如何参加这些优化，以及必须保留的依赖。能力定义位于 [execution_plan.py](../src/eip/execution_plan.py)，由测试与实际模块目录核对，新增模块不会自动获得局部执行权限。

“可局部”表示具备推导所需空间输入范围的资格，不等于可以把该模块移动到裁剪之后，也不表示所有参数组合、CPU / GPU执行器均已有批量实现。未知组合在相应片段沿兼容路径执行。具体启用范围以运行记录中的实际计划、设备与范围计数为准。

## 全模块审查

| 模块 | 空间依赖与优化方式 | 时间依赖及必须保留的边界 |
| --- | --- | --- |
| `intensity` | 逐像素，可限制空间范围 | 保留整数原类型的舍入、裁剪和每节点精度，不能将多节点合为一次舍入 |
| `affine` | 逐像素，可限制空间范围 | 保留float64中间量、非有限结果规则及显式精度 |
| `gain_offset` | 逐像素，可限制范围，独占且布局适合时可复用输出缓冲 | 保留目标单路、native整数转换及显式精度，不改共享输入 |
| `curve` | 固定逐像素曲线，可限制范围 | 非线性曲线必须在归约前逐像素执行，不能改为对均值施加曲线 |
| `threshold` | 每个空间位置读取所需颜色分量，可限制空间范围 | 保留颜色平均、uint8标签输出，标签不能暗作光强 |
| `calibration` | 固定曲线逐像素，可限制范围 | LUT需对完整输入验证码值覆盖；配准前左右暗场不同时保留传感器中线含义；标定先于插值 |
| `fixed_normalize` | 标量或按P广播的固定尺度可局部 | 先解析绑定并验证全部尺度；空间变化的尺度必须同步裁切，未适配时停止前推 |
| `grayscale` | 每空间位置读取颜色分量，可局部 | 保留RGB / BGR及均值或luma定义，不跨C归约改变顺序 |
| `color_convert` | 每空间位置排列或扩展颜色，可局部 | 灰度扩展、RGB / BGR变换及C轴保持明确 |
| `alignment` | 固定采样映射；静态索引、掩码和插值权重一次构造，映射所需输出区域 | 原图共同范围、镜像、偏移、插值零权重和无效掩码保留；设备选择不被融合覆盖 |
| `roi_crop` | 选择空间子域，需求坐标合成；紧凑结果接管主路 | 保留直接输入坐标、origin与dtype；小视图不能长期持有无用大图 |
| `spatial_roi` | 兼容裁剪可合成子域；均值、总和或分位模式消费其完整选区 | 保留旧有效像素规则，不把空间归约结果伪装成1×1图像 |
| `select_channel` | 选择P中的一路；可沿上游传递空间需求 | 主路P轴和含义实际改变；上游其他消费者所需幅面不能被移除 |
| `point_extract` | 选择一个空间位置，其所需范围可回推 | 保留T / Q / W轴；`output=side`时主路仍完整透传 |
| `line_extract` | 轴线或线段需求可映射为包围域；双线性需相邻采样 | R轴、真实距离、端点、最近邻或双线性权重保留；旁路不裁主路 |
| `axis_slice` | 空间轴可选择条带，P / C可选择分量；按实际轴推导 | 选择序列轴时定位真实T / Q / W / N样本，不把Q当T；旁路和主路独立 |
| `paired_trace` | 点或矩形选区需求可回推；区域统计消费完整选区 | 保留左右对应采样、独立或共同有效像素及T、P；默认旁路是额外真实消费者 |
| `time_crop` | 空间范围透传 | 样本或真实时间选择，不按平均帧率猜索引；来源映射及实际帧保留 |
| `time_sample` | 空间范围透传 | 稀疏样本选择，后续W、τ按选后的直接上游计数 |
| `time_smooth` | 各空间位置独立，可带相同空间请求 | 需要完整时间窗口及状态，边界只输出完整窗；均值与精确分位机制不互换 |
| `time_bin` | 各空间位置独立，可带相同空间请求 | 每组完整输入样本参与，保留合帧贡献和尾组舍弃规则 |
| `gaussian` | 有限空间邻域，可推导半径halo | 原图复制边界、有效权重归一、原无效位置和求和顺序保留 |
| `box_blur` | 有限邻域，但首批保留完整当前输入执行 | 原实现验证全图finite，并使用全图积分前缀；局部重新累计可能改变舍入，不能只拿halo就替换 |
| `spatial_smooth` | 高斯模式与`gaussian`同类；均值模式与`box_blur`同类 | 保留方法、radius、sigma、目标通道、精度和边界，分类不能替代能力判断 |
| `time_statistics` | 消费完整直接上游空间 / 分量，作为小信号保存点 | 保留T / Q / W与显式P / C；独立或共同有效规则及归约累计保留 |
| `region_reduce` | 兼容空间归约，消费完整当前YX | 输出真实标量 / 向量，不能将后置点提取用于缩小该统计区域 |
| `global_statistics` | `scope=samples`按空间位置归约；其他scope还消费相应空间范围 | 完整当前序列统计，输出静态N；精确分位不能改成近似采样，绑定消费者保留 |
| `statistics` | 兼容序列统计，保留完整声明范围 | 全序列固定RMS与均值 / 方差端口；不能改成全域标准差 |
| `sequence_statistics` | 兼容统计提供者，需求包括实际端口 | 完整当前T序列，统计端口和后续尺度引用不能因主路裁剪而删除 |
| `distribution` | 消费完整当前输入的有限值产生B轴频数 | 固定边界时逐样本；自动边界需扫描完整上游范围，不能按后置ROI决定箱边界 |
| `parameter_binding` | 主路透传，解析后可传递空间需求 | 保留命名变量与实际前序参数 / 统计依赖；未解析引用是规划边界 |
| `data_tap` | 主路透传，同时完整交付直接上游 | 正式 / 试算、完成状态、截取点与来源保留；后置ROI不能裁掉截流输出 |
| `correlation` | 兼容固定图时逐空间位置；曲线时还消费定义的空间范围 | 按真实map / curve参数选择状态与输出轴，signed τ、float64与共同有效配对保留 |
| `correlation_map` | 逐空间位置，紧凑双路小信号适合块产出 | 顺序T按全局输出编号周期重建；块边界不能重置累计规则 |
| `correlation_curve` | 消费定义的ROI曲线估计范围 | Q轴各τ独立，负τ反向配对；区域总强度g²与逐像素g²空间平均不互换 |
| `correlation_window` | 逐空间位置，固定中心与τ | W轴单调扩展可复用；缩窗或随机访问重建，不能套用滑动T的256输出重建规则 |

## 消费者与所有权

主路终点、截流导出、修饰旁路、统计端口、参数引用和阶段检查都是实际消费者。所需范围应取其需求并集；无法可靠合并时保留该阶段完整输出。删除模块、关闭旁路或修改作用范围后，应按实际流程重新生成计划。

裁剪和归约的紧凑结果成为当前工作数据，完成最后一次消费的旧输入及时释放。ROI视图的逻辑字节数小于其底层分配时，计费与释放必须针对真实底层分配。共享预览、缓存、只读映射或GPU异步使用者存在时，不原地覆盖它们仍需读取的数据。

逻辑契约保留完整的真实输出形状。局部工作数组及缓存的键包含请求域、布局、精度和计划版本，完整中间阶段检查不能命中局部结果。预算计入完整源帧解码、必要的全输入校验扫描、静态索引、所有仍存活分支及交接暂存。

## 插件默认规则

现有插件只声明逐帧输入输出及参数，尚未声明局部依赖、全输入校验、随机状态或副作用。执行能力默认`unknown`，保留完整输入与兼容执行器；不能根据插件名称、分类或与某内置模块相同的标识推断局部、批量或原地权限。能力查询本身不加载插件代码，不打开LUT或来源。

未来插件扩展需明确声明并验证空间 / 时间依赖、完整输入检查、批量入口、别名、独占写入和资源需求，随后才参加相应执行优化。

## 运行记录与验证

`compile_execution_plan`仅从已验证实例、逻辑契约、设备记录和真实消费者生成版本化元数据，不执行算法、不选择设备、不改变参数。保留禁用实例、所有启用实例顺序、输入输出阶段、精度、作用通道、参数依赖及回退原因；计划指纹覆盖影响执行的配置与消费者，显示名称不影响数值指纹。

局部执行与全图兼容执行对照全部输出、有限性、坐标、时间和来源。特别检查ROI外非法LUT码值、ROI外NaN对均值滤波的错误行为、不同左右暗场、节点精度转换、旁路、统计引用、块边界和随机访问。能力声明的覆盖测试与这些数值回归共同防止将新模块错误纳入优化。
