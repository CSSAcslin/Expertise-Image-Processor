# 分幅工作流与双视窗 0.4.1

本轮围绕数据预览与数据处理，提供独立的数据视窗、结果视窗以及真正按顺序执行的模块串联。原始来源只读。0.4.0 的结果仍可打开。

## 操作流程

1. 导入、划分左右有效区，检查固定配准并接受标定。数据视窗保留原始双幅、左幅参考、对齐右幅、叠加四种内容。
2. 预处理默认选择固定线性归一 `y=x/M`，默认 M=1023，可按实际码值尺度修改。该曲线不截断、不逐帧自动拉伸。未确认相机线性响应时，归一后的数据仍属于保存码值。
3. 在“模块流程”拖动模块，或用上下箭头排序。线性缩放 / 偏置、空间高斯平滑、强度曲线可重复添加，每个实例有独立参数、启用状态和标识。可以指定插入位置，也可以复制 / 删除图像模块。
4. 在“关联计算”选择两个独立入口之一：
   - **τ 扫描曲线**：固定中心帧及点 / ROI，扫描负、零、正帧延迟。保存曲线和数值，不生成四维系数图。
   - **空间系数图**：固定一个有符号帧延迟，选择当前中心试算或按时间步长运行序列。新的界面任务仅计算所选 τ。
5. 数据视窗顶部的“选取 / 修改 ROI”进入左幅参考网格上的 ROI 操作，支持拖画、移动、边角缩放和精确整数坐标。退出工具仍保留 ROI 轮廓；几何映射发生改变后清除旧坐标选择，避免误用。空间图只保存 ROI 对应区域；曲线保留逐像素 g² 空间平均 / 区域总强度 g² 两种定义。
6. 本次结果名称可在运行前填写；留空使用来源、任务类型及时间自动命名。完成任务出现在左侧“处理结果”，点击后在结果视窗打开。数据帧位置与结果时间位置独立。
7. 在结果参数面板或任务详情中重命名。名称保存在运行记录中，项目重开仍保留。任务列表同时显示 W、延迟、中心 / 时间步长、ROI 等摘要；详情包含来源、范围、几何、强度曲线、固定尺度、有效性阈值、设备、精度、全部模块实例参数及日志。长窗口的累加阶段也报告窗口、延迟批次与配对进度，容量检查同时显示单遍配对更新规模。

可选择并排显示、仅数据或仅结果。显示色标不改变计算数据；系数图、曲线、全源统计图均显示在结果视窗。

## 可执行模块契约

`workflow.py` 提供带数据类型的有序执行器，流程上限 32 个模块。顺序与参数进入运行记录和全源统计缓存指纹。

| 模块 | 输入 / 输出 | 参数与行为 |
| --- | --- | --- |
| 强度校准 / LUT | 传感器图 → 传感器图 | 内置固定曲线或外部 LUT、左右偏置、饱和排除；位于空间采样之前 |
| 双幅划分与固定配准 | 传感器图 → 对齐双路 | 左右矩形、中线、平移、镜像、最近邻 / 双线性 |
| 线性缩放与偏置 | 传感器图 / 双路 / 系数图 → 同类型 | `y=gain*x+offset`；双路阶段可指定左 / 右 / 双路 |
| 空间高斯平滑 | 传感器图 / 双路 / 系数图 → 同类型 | 正 sigma、1～32 像素半径；可分离二维高斯核；边界复制，有效权重归一；原无效位置保持无效 |
| 强度曲线 | 传感器图 / 双路 / 系数图 → 同类型 | 固定输入尺度、曲线类型、幂指数、作用幅面 |
| 全源均值与固定尺度 | 对齐双路 → 双路与统计 | 全部输入帧的 Welford 均值 / 方差；保留尺度或各路一个固定 RMS；保留均值及正负涨落 |
| 标准二阶互关联 | 双路与统计 → 系数图 / 曲线 | 奇数 W、最少有效样本、最小局部均值；使用同一联合有效样本集合 |

四个结构模块各一个，通过“设置此模块参数”访问其专用编辑面板。图像模块可自由插入支持其输入类型的位置。输入类型或依赖不匹配时明确报错，不自动重排，也不静默跳过。全源统计和关联之间的数据类型为双路与统计，普通图像模块应放在统计前或关联后。

每个新增算法需要声明名称、输入 / 输出类型、独立参数校验与执行函数。目前提供上述内置模块；逐帧插件 / 机器学习模块的适配需实现同样的序列与数据类型契约。

关联后的模块处理会标记 `result_semantics=processed_g2`，并记录后处理顺序及原 g²=1 经处理后的基准。其数值不能与未处理的标准 g² 混淆。τ 曲线不接受关联后的空间高斯平滑，避免只选一个点时以不完整空间上下文做卷积；可将平滑放在关联之前，或单独处理已保存的系数图。

## 曲线预设

令 `u=x/M`：原值为 x，线性归一为 u，平方根为 √u，平方为 u²，幂函数为 u^γ，对数为 ln(1+9u)/ln(10)。所有参数在整段序列固定。超出函数定义域或非有限输出标为无效；没有隐藏的范围截断。非线性曲线会改变强度涨落及 g²，应作为实验处理选择并记录。

外部 LUT 与内置曲线二选一。暗场偏置使用曲线 / LUT 后单位，饱和阈值使用进入校准模块的码值单位。全源时间均值仍与单独测量的暗场不同，标准 g² 继续保留强度均值分母。

## 验证

`tests/test_split_workflow.py` 独立核对预设曲线、重复模块与顺序、预览 / 正式执行一致、直接 g² 公式、关联后变换、缓存隔离、名称持久化及非法流程。`tools/smoke_split_workflow.py` 在隔离的 Edge 浏览器中检查双视窗、ROI、独立入口、模块复制 / 拖排、改名、CSV / TIFF 导出、刷新恢复及 1440×960 / 1100×760 布局。测试输出保存在 `.test-output`，不修改实验文件。
