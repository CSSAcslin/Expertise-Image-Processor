# 模块驱动工作台：GUI 与交互重做规划

状态：已实施为 0.7.0。基线版本：0.6.0；核对日期：2026-10-12。操作及验收记录见 [MODULE_WORKBENCH_0_7_0.md](MODULE_WORKBENCH_0_7_0.md)。本文保留原设计目标，实际能力边界以该记录和当前模块目录为准。

规划阶段只盘点界面和制定方案。用户随后确认按本文实施，并增加“数据截流导出”修饰模块（含导出到数据预览）。实施以最新三类模块要求为准：ROI 只负责空间裁剪，区域运算移到修饰模块。此前文档中将两者合并的定义随实现迁移，不继续沿用为新界面设计。

## 1. 当前界面核对与改造目标

已核对正在运行的本机 0.6.0 服务、1600×1000 / 1100×800 页面，以及 0.6.0 既有分幅流程验证截图。当前页面通过独立浏览器上下文只读检查，因此不代表用户已打开标签页中尚未保存的参数和布局；未读取或改写该浏览器草稿。检查前后服务任务标识保持不变，没有启动算法任务。

现有可复用基础：16 个内置模块、契约3的轴/尺寸/含义校验、按需序列执行器、共享原始预览、独立结果视窗、真实时间与来源映射、项目及正式结果存储。

需要解决的问题：

| 现状 | 改造决定 |
| --- | --- |
| 模块在右侧窄列，默认流程240px、参数310px同时展开 | 流程编排成为主工作区，参数是所选模块的检查器 |
| 通用与分幅仍各维护一套流程/参数面板 | 一套模块库、一套流程、一套检查器；模式只保留为流程模板 |
| 节点堆叠编辑按钮、上下移、启停、复制、删除、长契约说明 | 节点缩为图标、名称、关键参数、端口及状态，低频操作进入菜单 |
| 参数、数据契约、试算、设备和导出在相似表单里连续堆叠 | 模块参数、只读定义、工作台运行、结果管理四种职责分开 |
| 线性变换名称相近，ROI裁剪与归约、统计与归一合并 | 按真实行为拆分或消歧，不仅替换显示名称 |
| 公式主要留在文档；检查器通常只展示描述 | 模块统一提供公式、符号表、条件、输入输出和实例说明 |
| 大量正常状态文字反复解释相同规则 | 正常状态使用简短状态标记；完整解释按需打开 |
| 窄窗口持续压缩预览，收起右侧面板还会隐藏运行按钮 | 自适应停靠/浮窗；工作台运行条始终独立可见 |
| 结果导出散落在结果窗、分幅参数区、任务详情 | 最终导出归结果工作区；中途截取由修饰模块明确记录 |

目标工作流：**选择来源 → 组织模块 → 编辑选中实例 → 检查阶段输入/输出 → 试算与正式运行 → 检查、提取及导出结果。** 视频预览与数据处理始终贯通，普通原始播放不执行流程。

## 2. 三类模块的职责与清单

分类按用途，不替代输入输出契约。中间模块同样有公式；修饰模块也可能改变形状。不能依靠类别决定连接是否合法。

| 类别 | 面向用户的副标题 | 核心职责 | 图形识别建议 |
| --- | --- | --- | --- |
| 中间模块 | 数据编辑 | 裁剪、采样、平滑、合帧、强度/颜色转换 | 蓝色类别标记；裁剪框、采样点、窗口、合帧等独立图标 |
| 算法模块 | 科学计算 | 标定、配准、分割、关联等有明确数理含义的核心计算 | 琥珀色类别标记；标定曲线、对齐框、阈值、相关波形等图标 |
| 修饰模块 | 提取与传递 | 区域运算、信号提取、统计、阶段保存、幅面选择及参数绑定 | 紫色类别标记；取点、线段、切片、分布、保存、连接等图标 |

颜色只辅助识别，始终配图标及文字。错误/无效状态使用独立状态图标，不能与类别颜色混淆。

### 2.2 本次需要建立的修饰能力

1. **数据截流导出**（用户新增并确认）：在放置位置获取直接前序模块的输出，主路原样继续；可选择导出到数据预览、类型化数据文件或适用的数值表。可选完整序列或明确样本范围，保留该截取点之前的完整流程、真实轴与来源。进入数据预览的正式输出可明确作为下一流程输入；试算输出标明临时状态。不能将“截流”误作中止后续模块，也不能静默将图像矩阵转换为标量表。
2. **点信号提取**：从 `T×Y×X` 选择 `(x,y)`，得到随T变化的信号；从 `Q×Y×X` 提取得到随τ变化的信号。T和Q分别标注。
3. **直线剖面提取**：给定端点，选择固定T/Q截面或保留该轴，得到位置R或T×R/Q×R；声明插值和位置距离单位。
4. **截面提取**：选择命名轴与索引/真实坐标，如固定T得到YX、固定X得到TY；实际输出轴随选择改变。
5. **区域归约**：均值、总和、分位值，独立于ROI裁剪；改变主路时以真实标量/向量输出，不能伪装成1×1图像。
6. **分布统计**：指定区域、截面或轴，得到箱边界、计数/频率等具名结果；固定范围、箱数、无效样本数及归一方法明确。
7. **幅面选择**：明确选择P轴中的一路，保留来源与对齐坐标。
8. **参数绑定**：将前序实例的某个参数或具名结果作为后续参数，如统计尺度、参考图、阈值或LUT。仅目标参数声明支持时可绑定。

灰度/颜色转换作为中间模块新增；需要明确输入色彩语义、权重、输出dtype和轴变化，不能把任意通道平均称为通用亮度转换。

### 2.3 修饰模块的两种数据作用

- **旁路采集**：阶段保存、观察性统计、独立曲线提取等默认生成附加结果，主路保持不变。节点显示一个主输出及明确的旁路结果端口。
- **替换主路**：区域归约、幅面选择，或用户明确选择“将提取结果继续处理”时，主输出变为提取结果。下游重新校验形状、轴与科学含义。

节点明确标注作用，不靠隐藏开关自动改变后续计算。参数绑定使用独立的参数连接，不与图像数据连接混用。初版保留一条有序主数据链，增加受约束的旁路结果和前向参数引用；不同时扩展任意多输入、反馈循环或无限制图编程。

## 3. 新工作台布局与窗口

默认采用可停靠工作区，以流程编排为核心，保留独立数据/结果视窗。数据来源和模块库按需打开，不长期占据两条窄侧栏。

```text
┌ 项目 / 导入 / 流程模板 / 窗口布局 ─────────────────────┐
│ 来源与模块库    流程编排主窗口                  模块检查器 │
│ （可收起）      模块 → 模块 → 模块               参数      │
│                 ↓ 旁路结果 / 参数连接           公式      │
│                                                输入输出  │
│                 数据视窗       结果视窗                    │
│                 原始/阶段输入   图像/信号/分布              │
│                 播放与定位      结果定位与显示              │
├ 试算 / 正式运行 / 取消 / 任务状态 / 运行设置 ──────────┤
└ 任务与运行记录（可展开）─────────────────────────────┘
```

- **流程窗口**：默认位于中央上部、跨较大宽度，支持横向有序编排、拖动排序、插入点；长流程滚动/缩放，不把整条链压缩到不可读。
- **数据视窗**：原始数据与显式选择的阶段输入/输出使用公共预览引擎；标题明确对象。切回原始数据一键完成。
- **结果视窗**：浏览最终和旁路结果，按类型显示矩阵、曲线、剖面或分布；保存独立定位与显示状态。
- **模块检查器**：只编辑当前实例，支持锁定选中对象；不会因为播放换帧而切到另一个模块。
- **模块库**：可搜索，按三类筛选；内置、自定义、收藏作为筛选条件，不再另建执行系统。“新增自定义模块”是唯一注册入口。
- **任务抽屉**：进度、失败、日志和完整运行记录；最终导出操作归选中的结果，任务记录可定位对应结果。

### 窗口策略

流程、检查器、数据、结果四个窗口支持停靠、收起、最大化、恢复与页面内浮动。浮窗可移动/缩放、置前、吸附回停靠区；关闭只隐藏视图，不删除流程或结果。

初版使用页面内浮窗，仍共享同一个状态与播放器控制器；不为浮窗创建第二份reader、播放循环或模块参数。真正独立的浏览器弹窗/多屏窗口暂不作为首版前提。

布局适配：

- 1600×1000：流程、检查器、数据与结果同时可用，模块库按需展开。
- 1366×768：来源默认收起，流程与双预览分配可调高度；任务默认折叠。
- 1100×800及960×760：优先保护流程可读性和预览最小空间；检查器可切换为抽屉/浮窗，不能继续强留两列右侧面板。原始播放和运行按钮始终可达。

布局状态与算法状态分开保存。调整窗口、切换视图、改图标或实例别名不触发数值重算。

## 4. 模块窗口的关键交互

### 模块库与流程编排

- 模块库每项只显示“图标＋明确名称＋一句用途”；选中后提供输入输出和示例预览。
- 添加支持双击/按钮插入到当前选中节点之后，也可拖到明确插入点。模板只载入一条可编辑流程；替换已有非空流程前展示差异，不静默清空。
- 节点默认显示类别图标、名称/自定义别名、1～2个关键参数、简短主输出及运行状态。完整契约只在选中检查器展示。
- 点击节点即选中并编辑；去掉每张卡重复的“编辑此模块参数”。复制、删除、上移/下移、改名进入节点菜单，启停保持直接可见。
- 支持重复模块及独立参数；复制生成新实例ID。键盘可完成选择、移动、复制和删除，不把关键操作限定为拖动或悬停。
- 流程编辑具备撤销/重做；删除被引用的节点、停用必要提供方、重排产生非法引用时，显示具体依赖位置，不偷偷重接或补模块。
- 连接正常只显示紧凑标记；错误直接落在节点/连接上，例如“此处需要Y/X空间轴，上一步已输出T信号”，提供定位到修复节点的动作。

### 参数检查器

检查器固定为三个内容页：

1. **参数**：只显示当前模块相关、当前模式适用的字段。先主参数，再折叠高级参数；数值附单位、界限、默认值恢复。ROI、中线、点/线工具归相应实例。
2. **公式与说明**：可排版公式、符号表、定义域、有效样本/像素规则、边界及小例子；允许放大查看，不把学习内容塞进所有节点。
3. **输入输出**：直接上游、实际轴/尺寸、dtype、科学含义、主路/旁路、参数来源和坐标/时间映射；明确区分静态估计、已编译契约与实际运行结果。

检查模块输入/输出位于节点工具栏或检查器顶部的一处统一入口，明确这是显式计算检查。执行设置放工作台“运行设置”中；当前实例的设备/精度/预算覆盖作为高级项单独呈现，并显示继承还是覆盖。

项目打开/保存不放参数页；最终导出不放参数页；修改输出目录不伪装成算法参数。

### ROI与取样工具

- 选中“空间裁剪ROI”时直接出现“绘制 / 修改ROI”和坐标字段；画布标注正在编辑的实例及其输入坐标。
- 修饰模块的取点、线段、区域统计使用相应工具，选择形状可以共享几何组件，但参数归属各自实例。
- 检查器与画布双向更新，支持撤销和数值精调；原始播放不隐式执行上游配准或统计。需要阶段输入时明确请求检查，缓存失效时标注待更新。

## 5. 公式、命名与视觉层级

### 公式元数据

统一目录补充：类别、图标、短用途、公式、符号定义、参数单位/条件、输入输出端口、边界、无效值、示例和版本。

公式由已实现内核与测试核对，不从旧隐藏表单复制。公式组件及资源本地打包；自定义模块可声明文档和公式，未提供时显示“未提供公式说明”，不能生成看似权威的猜测公式。

关联模块至少明确展示：

`g²(τ;c) = [Σ(i∈V(c,τ)) L_i R_(i+τ) / |V|] / ([Σ L_i / |V|] [Σ R_(i+τ) / |V|])`

其中V是当前中心窗口中、两路共同有效的配对样本集合；分子与分母使用同一集合。右路索引为左路索引加τ，τ可负、零、正，不能假设正负对称。W、τ与步长按直接上游样本计数，并提供真实配对时差。样本不足或均值低于阈值的无效结果明确说明。

必须可直接对照两种流程：

- `区域平均/总强度 → g²`：区域信号的关联。
- `逐像素g² → 区域平均`：像素系数的空间平均。

公式页和结果标题都区分两者，不能只显示模糊的“ROI关联”。

### 文字精简原则

- 正常节点不重复“按顺序执行、原始预览可用、显示不改变数据”等长说明。
- 操作提示仅在首次使用、当前焦点、错误或真实限制出现时显示。
- 保留未知帧/时间、降采样、无效值、过期结果、范围边界和科学含义警告，不因减少文字而隐藏它们。
- 所有模块名称按动作和对象命名；显示名、用户别名、稳定算法标识和版本分别保存。

### 视觉规范

保留适合科研查看的中性暗色底，提高正文和标签对比度；建立标题、主参数、辅助信息三级字号层级，不再以10px级文字承载关键配置。三类模块的类别标记与各自图标保持一致。

参数编辑使用清晰字段组；公式为阅读排版；输入输出为只读结构表；运行设置为工作台抽屉；结果导出为结果动作菜单。通过位置与结构区分职责，避免所有板块都是相似折叠卡片。图标使用统一风格的本地矢量资源，图标按钮有可访问名称。

## 6. 计算契约、修饰模块与兼容

### 需要扩展的契约

- 当前轴契约T/Q/P/Y/X/C继续保留；直线位置R、分布箱等新轴显式声明，不伪装成时间或颜色通道。
- 增加具名主输出、附加结果端口、参数绑定描述及主路作用。类型含轴、shape、dtype、单位、科学含义、来源映射和无效值策略。
- 参数引用初期只允许前序实例的明确参数/结果端口；禁止向后引用、环、任意代码表达式和隐藏全局变量。数组引用必须有形状/类型/单位约束，不将图像默认当标量参数。
- 复制绑定节点默认仍引用原提供方；复制提供方不自动重绑定消费者。重排/删除/启停后重新检查依赖。
- 绑定要声明取值范围：固定全序列统计、指定样本，或目标参数明确支持的逐样本结果。全源统计不允许随当前播放位置变化。
- 引用与侧结果参与实际执行、预算、取消和缓存指纹；别名、布局、图标和帮助展开状态不参与数值指纹。

### 正式存储

主结果与附加结果以具名工件组织，每项保存提供方实例、截取阶段、上游顺序/参数/版本、输入来源、坐标/时间/贡献样本映射、输出语义和状态。

截取导出在正式运行中使用新输出目录和`.partial`事务；失败或取消的侧结果不冒充已完成结果。试算可观察/暂存侧结果，但不因普通预览或拖动参数自动写盘，也不默认导出整段数据。最终结果导出是工作台动作，中途保存是流程中的可复现模块，两个入口职责清楚。

NPY/CSV用于完整数值，图像/曲线/分布按类型提供TIFF/PNG/SVG；保持已有来源链和“正式结果作为下一阶段输入”的明确操作。试算缓存仍不能当作长期来源。

### v0.6.0兼容迁移

1. `spatial_roi(pixels)`映射为空间裁剪；旧mean/sum/quantile映射为“同位置裁剪 → 区域归约”，保持原共同/独立有效集合、坐标映射及科学含义。旧实例ID保留给最终归约输出，新裁剪实例独立ID。
2. 当前statistics不仅提供均值/方差，还实际执行`输入 / scales`；即normalization=none、scales=1，也会输出float64。拆成统计与归一时保留精度、每路固定尺度及非法/极小尺度回退为1的规则，不能悄悄变成整数透传。
3. 旧correlation按map/curve映射到两个明确入口，保留中心、窗口、延迟、步长、阈值及输出轴。
4. 名称/图标变化不改变旧算法ID含义；发生拆分或执行契约变化时使用新的模块/流程版本，不只改版本号而缺少迁移。
5. 已完成历史结果按原记录读取，绝不重新解释或覆盖；旧项目另存迁移副本，展示实例映射和需人工核对项。
6. 旧GUI隐藏字段及双模式表单从新页面清理；历史兼容放在迁移/读取层。新执行继续复用SequenceEngine，不回退到旧module_engine维护另一套算法行为。

## 8. 验收清单与范围

- 模块库按三类查找，能够新增可信自定义模块；同一实例的参数只有一处事实来源。
- 模块可添加、重复、复制、启停、删除、拖动/键盘排序；界面顺序与实际计算一致，撤销可恢复实例与依赖。
- 所有内置模块有与实现一致的公式/算法、符号/单位、输入输出、边界；未完成的自定义文档不冒充内置说明。
- 选择ROI/点/线实例后，画布工具与坐标归属清晰；作用于直接上游数据，原始预览仍独立。
- 原始视频按真实帧/时间定位和播放，不因切换模块、查看公式或窗口移动执行配准、背景统计或关联。
- 数据与结果独立显示、定位、播放及设置色图；T结果与Q结果使用不同定位语义，不能误当采集时间。
- 输入类型错误、缺少依赖、失效参数引用定位到具体节点/字段；允许继续编辑和原始播放。
- 用手算数组验证ROI拆分、时间sample/smooth/bin、区域与像素g²差异、正负τ、统计归一及类型策略。
- 用`T×Y×X`小数据验证点信号、直线、截面与分布的完整数值和轴；侧输出既不丢来源，也不暗改主路。
- 正式导出包含完整参数、引用解析/哈希、提供方、范围、贡献映射与状态；失败/取消不发布完整结果。
- 大小窗口可读，主要参数与运行控制不被挤出；浮窗停靠恢复、选中状态、刷新/项目恢复不复制播放器或丢参数。
- 历史完成结果原义保留，旧项目可明确迁移且不覆盖原文件；用户已有数据、来源与任务不因GUI升级被清空。

本次不同时迁入LifeCalor参考清单的40组算法，不扩展Δx/Δy扫描、多人协作、任意反馈图编程、训练平台或独立多屏弹窗。参考算法和机器学习后续通过同一模块契约接入，不再增加孤立的模式页面；现有逐帧插件的能力边界不能因更换GUI而被夸大。
