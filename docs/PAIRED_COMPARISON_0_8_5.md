# 0.8.5：双幅时序与多曲线比较

## 工作流

导入双幅序列 → 固定双幅配准 → 选取对应点 / 区域 → 保存左右时序 → 结果窗叠加比较 → 导出完整数值与来源。沿用公共视频预览、独立检查进程与统一处理链。

新增算法模块「双幅时序比较」可以从模块库独立添加，不是 g² 模板的必需步骤，也不计算新的相关系数。

## 算法定义

输入为配准后的灰度强度 `TPYX`，输出为左右时序 `TP`。坐标相对此模块直接输入，画布选择在左路进行，右路使用配准后的同一坐标；支持参数输入及画布取点 / 矩形选区。不能把单幅、标签或 g² 系数接入本模块。

- 对应点：`s_p(t) = A_p(t,y,x)`，保留两个幅面及全部时间样本。
- 对应区域：在每个时间样本内分别对左右矩形区域统计；可选均值、最大值、最小值、总体方差（分母 n）、标准差、总和、线性插值精确分位值、有限值计数。
- 共同有效：该帧区域内左右都有限的对应像素参与两路统计；点选时任一路无效，两路均无效。独立有效：各路使用自身有限像素。空集合 count=0，其余输出 NaN。
- 默认输出旁路，主路原样继续；可重复添加多个点 / 区域。选择替换主路时，后序接收真实 `TP` 时序，不再包含空间轴。
- CPU / 可选 GPU 共用统计定义。默认 float64，区域 count 为 uint64；旁路遵循现有精度规则，不改变主路精度。

模块实例、对应坐标、范围、统计量、有效值规则、上游流程、来源及真实时间随保存结果传递。自动结果名称包含点坐标或区域统计与尺寸，可继续自定义。

## 结果窗

时间 / 延迟曲线默认同时显示当前结果各分量，最多 32 条；更多分量可在添加结果时明确选择。可从不同运行、来源或旁路端口加入曲线，数据清单支持：

- 勾选显示、改名和颜色；从比较移除曲线不删除保存结果或文件。
- 单选取值焦点，点击图中附近曲线也可切换；光标显示对应横轴坐标、焦点值，展开清单可同时查看各曲线值。
- 横轴滚轮缩放、拖动左右浏览；纵轴刻度区域滚轮缩放纵轴；双击或适应按钮恢复完整范围。
- 桌面清单可折叠并滚动；高度不足时自动收起，展开使用浮层，保留图形面积。仍可使用现有结果窗口的浮动及最大化。
- 刷新草稿或保存项目时保留比较条目、名称、颜色、显隐、焦点及横轴选择。被移除的运行同时从比较清单去除。

单组分布继续使用强度—频数直方图；多组同箱分布叠加频数曲线。静态一维记录及一维剖面也可比较；多轴截面须先用「按轴截面」提取一维，避免隐式展平坐标。

## 校验与显示边界

逐曲线检查完整长度和横轴，而不是只核对网页抽样点。时间 T、延迟 Q、距离 R 和分布箱 B 不混用；Q 核对有符号延迟，剖面核对距离，直方图核对完整箱边界。选择真实时间 / 时差时要求全部已知并完全相同，不自动插值、截短或按平均帧率推算。

按样本号叠加允许真实时间不同，但明确提示「按编辑后样本号对齐」；延迟样本相同而实际配对时差不同也会提示，未知时间显示说明。不同科学含义共用纵轴时提示未归一化，用户可隐藏曲线或分别比较。显示最多约 2000 点 / 曲线，折线不连接显示中的无效点；光标读取的是显示点，精确全量数值从比较包或各结果 NPY / CSV 导出。

比较只读取已完整保存的类型化结果，不触发算法重算或进入任务队列。矩阵请先提取点、时序统计或截面；阶段检查仍只显示当前样本，不能将未保存检查值误称为完整时序。

## 导出与验证

结果窗下载图标导出 `comparison.zip`，包含：

- `values.csv`：全部坐标和全部已加入曲线值，包括暂时隐藏的曲线；非有限值为空。
- `comparison.json`：软件版本、曲线来源、模块与完整运行参数、坐标校验摘要、临时 / 正式状态、显示设置及焦点。

按行写入临时磁盘，单次下载后清理；原数据与结果不改写。单个模块仍可导出 NPY、CSV、PNG / SVG 及完整运行包。

专项命令：

~~~powershell
.\.venv\Scripts\python.exe -m pytest tests\test_paired_comparison_0_8_5.py -q
.\.venv\Scripts\python.exe tools\smoke_paired_comparison_0_8_5.py
~~~

浏览器验收使用模拟 uint16 TIFF，覆盖实际画布选点 / 选区、同一流程两个模块的四条曲线、显隐、焦点、改名、横纵缩放、完整比较包、刷新恢复和移除曲线。桌面 1600×1000 与小窗口 1024×768 均检查截图；报告与图片写入被忽略的 `.test-output/paired-comparison-*`。本机没有 CUDA，设备路径数值对照使用主机数组适配器，不能替代 CUDA 真机测试。
