## 结果管理

在结果视窗右上角点击 **管理**，或在左侧“来源 → 处理结果”点击 **管理**。每条结果也有“导出 / 删除 / 作为输入”入口。

- 选择运行和具体输出：主输出、截流及其他附加输出共用预览。正式矩阵、双路、标量及向量结果均可作为新输入，完整类型与来源继续传递。复用结果清空当前模块链，保留撤销。
- “参数与来源”打开已有任务详情，查看模块顺序、实例参数、范围、来源、资源快照与实际设备；名称可修改并写回运行记录。
- **导出完整运行包**：ZIP64 中包含整个运行目录、数值、样本映射、参数、来源以及附加输出。部分失败任务的失败状态仍保留，不把未完成数组标成完成。打包逐文件写入临时磁盘，使用未压缩 ZIP，需输出体量加 32 MiB 的临时空间。
- 单独 NPY / CSV / TIFF / 曲线导出仍在结果信息面板；浏览器直接下载，不把整个数值文件构造成浏览器内存 Blob。下载链接随机、仅本机、一次有效，五分钟未使用即过期。
- **删除**先展示完整目录、文件数量、体量和当前工作区依赖。默认仅移除任务及对应结果引用，数值文件和已创建的派生输入保留。选择永久清理时只清理这次运行的目录；派生来源、后续任务或文件下载仍在引用时拒绝清理。已另存的项目文件无法自动追踪，界面明确提示。
- 结果引用保存在工作区 `.eip-results.json`，重启可继续预览、导出或复用。缺失 / 不匹配记录不会恢复；也可输入保存的 `run.json` 重新打开。旧的通用 TIFF 运行通过项目文件恢复。大数组保持磁盘映射，结果索引不加载完整数组。

## 内存与缓存

进入底部 **运行设置 → 统一资源预算**。设置保存在工作区 `.eip-resources.json`，应用于后续提交；正在执行时保存按钮禁用，现有任务保留提交时快照。

| 设置 | 作用 |
| --- | --- |
| 总工作内存 | 工作数组与应用缓存的统一预算，默认按物理内存的四分之一设置，最多 2048 MiB |
| 预览缓存 | 读取缓存与 Web 原值缓存各占一半，最多保留 6 个原值帧；超大单帧明确要求提高预览预算 |
| 计算缓存 | 包含在计算份额内，不额外增加总预算；每个工作进程最多使用其份额的三分之一，读取缓存占其中四分之一 |
| 显存上限 | CuPy 内存池限额；任务和检查按 3:1 分配 |
| 默认设备 | CPU / 自动 / GPU；新模块默认继承，支持 CPU 专用节点与 GPU 算法混合 |

扣除预览份额后，处理预算的四分之一（最多 256 MiB）预留给阶段检查，剩余用于一个正式 / 试算任务。正式任务串行；运行中仍可检查模块与预览原始数据。界面显示系统可用内存、各进程实际驻留内存、原值缓存量和份额。

模块执行覆盖中的空白内存上限表示继承，填写数值只能收紧工作进程预算。旧项目中明确保存的 CPU / 256 MiB 等值继续作为显式覆盖；可点击运行设置中的“流程继承统一资源”一次清除整条流程的设备 / 内存覆盖，或逐实例调整。精度仍归实例所有，流程调整可撤销。

“释放空闲缓存”释放 Web 原值缓存、重启空闲读取进程、关闭空闲检查进程；不删除输出或停止正在计算的任务。原值查询需重新定位后恢复。

均值和合帧继续逐样本累加。**窗口精确分位值**改为磁盘临时数组和预算内分块归约，保留线性插值定义及有限值规则，取消 / 异常后清理临时窗口文件。结果、统计的保留数组、嵌套时间工作数组与缓存合计估算，超预算说明具体模块与修复方式。

预算不是整个进程 RSS 的硬限制：Python、解码库、CINE 索引、显示生成、CUDA 上下文、第三方插件和操作系统文件页缓存仍有额外占用。不能据此承诺任意大小单帧或任意算法都能运行。CPU / GPU 之间的数据传输及磁盘分位值也有成本。

## GPU 支持范围

| 模块 | GPU 实现 |
| --- | --- |
| 增益 / 偏置，兼容强度与仿射 | float64 中间计算；保留输入类型时使用相同四舍五入和裁剪规则 |
| 空间平滑，兼容均值 / 高斯 | 均值采用反射边界积分和；高斯采用两次一维卷积、边缘延展、有限值权重及原始 NaN 位置保留 |
| 固定强度映射 | identity / linear / sqrt / square / gamma / log，与 CPU 共用定义 |
| 阈值、固定尺度归一、灰度 | 同一阈值、尺度、RGB / BGR 与亮度权重定义 |
| g² 固定延迟图、延迟扫描 | float64 滚动矩；同一联合有效样本、最少计数与最小均值，保留负 / 零 / 正 τ 配对 |

ROI、时间编辑、配准、LUT 校准、统计、信号提取、插件和交付等模块继续使用 CPU；模块库声明能力，不把这些步骤误报成 GPU 计算。模块参数、左右作用范围、精度及顺序实际参与执行。

自动模式仅在 CUDA 探测 / 启动自检失败时回退 CPU，日志和运行记录保存原因。显式 GPU 不可用时失败；运行中显存不足或计算错误保留失败状态，不自动改变设备继续运行。

CUDA 12 环境可选择安装项目可选依赖，CPU 安装无需改变：

```powershell
.\.venv\Scripts\python.exe -m pip install ".[gpu]"
```

其他 CUDA 版本按 [CuPy 官方安装说明](https://docs.cupy.dev/en/stable/install.html) 选择对应发行包，避免同时安装多个 CuPy 发行包。内存池限制及其不包含 CUDA 上下文等开销的边界见 [CuPy 内存管理](https://docs.cupy.dev/en/stable/user_guide/memory.html)；高斯 GPU 卷积接口见 [convolve1d](https://docs.cupy.dev/en/stable/reference/generated/cupyx.scipy.ndimage.convolve1d.html)。
