## 工作流

1. 导入来源，在数据视窗定位、播放和检查原始数值。
2. 从模块库按类别搜索并添加模块，或载入一条可编辑的流程模板。
3. 点击流程节点编辑参数；切换“公式与说明”了解定义，切换“输入输出”核对真实轴、尺寸、类型和科学含义。
4. 需要选区时，使用当前模块的画布工具。选区属于该实例，坐标相对其直接上游；检查完可以返回原始数据。
5. 显式检查阶段或试算。输出目录、批处理和任务名称属于工作台运行设置；设备、精度与内存预算收进实例执行覆盖，不与主要算法参数混排。
6. 正式运行后，在结果视窗选择最终结果或附加输出，检查、导出，或明确作为下一流程的输入。

原始播放、查看公式和调整窗口布局不执行算法。编辑中出现不兼容连接时仍可查看原始数据；执行前必须修复具体节点的错误。

## 三类模块

| 类别 | 职责 | 示例 |
| --- | --- | --- |
| 中间模块 · 数据编辑 | 改变数据形态、采样或数值表示 | ROI 裁剪、间隔采样、时间滑窗、时间合帧、灰度转换、固定尺度归一 |
| 算法模块 · 科学计算 | 具有明确科学定义、公式及输入输出要求的核心运算 | 传感器强度标定、双幅配准、阈值分割、固定延迟 g² 图、延迟扫描 g² |
| 修饰模块 · 提取与传递 | 获取、归约、统计、导出或传递流程中的数据 | 区域归约、序列统计、点信号、直线截面、按轴截面、分布统计、双路选幅、数据截流导出 |

类别帮助查找，不决定连接是否成立。例如区域归约属于修饰模块，但替换主路后会移除空间轴，不能再接空间高斯滤波；双路选幅移除 P 轴后也不能直接做双路关联。

旧 `spatial_roi`、`statistics`、`correlation` 定义只用于历史兼容。新模块库使用职责明确的节点，不继续提供同名、同义但行为不同的模式专属算法。

## 流程与窗口

每个节点拥有独立 ID、版本、参数和启停状态。支持重复添加、复制、拖动排序及键盘移动；实际执行顺序与界面一致。删除节点会删除它的计算，停用节点原样传递主数据。编辑操作可撤销、重做。

模块库负责发现和添加；流程负责组织顺序；检查器只编辑选中的实例。节点显示图标、名称、关键参数和状态，长说明收进公式页与输入输出页。

流程、检查器、数据和结果窗口可以调整显示方式。页面内浮窗仍使用同一份实例状态和预览控制器；关闭窗口只是隐藏视图。布局、图标、实例别名不参与数值计算指纹。

左侧数据 / 模块库的右边界、任务记录的上边界可拖动调整，任务栏折叠时也可向上拖动展开。边界支持方向键微调和双击恢复默认；调整后的尺寸随布局保存，折叠再展开、刷新页面不会丢失。尺寸限制为主预览、播放和定位控件保留空间。

数据和结果各自维护定位与显示设置。显示窗宽、伽马和色图不改变算法输入；需要修改数值时使用明确的强度、灰度或标定模块。

一维结果（点信号、时序 / 延迟曲线、直线剖面和直方图）支持滚轮围绕鼠标位置缩放：绘图区缩放横轴，左侧纵轴刻度区缩放纵轴，两个轴独立控制；按住左键左右拖动浏览。双击图表或在“结果”单视窗点击“适应”，同时恢复两个轴的完整范围。切换同一结果的样本及调整窗口大小保留视野；手动缩放后的纵轴数值范围保持固定，未缩放时跟随当前样本自动适应。切换数据、输出端口或横轴含义后重新适应。这些操作只调整本地显示，不执行算法、不修改数值或导出数据，已有显示抽样提示继续保留。

双路模板预载时间范围、固定线性强度标定、配准、ROI 裁剪、序列统计及对应 g² 模块。固定尺度按已声明保存位深初始化，浮点来源使用尺度 1；需由使用者核对输入物理含义。模板是可修改的起点，载入前展示与当前流程的差异。

## 参数、公式与输入输出

- **参数**：只显示该模块当前适用的字段；坐标、窗口、延迟和采样设置说明单位与计数方式。
- **公式与说明**：显示实现采用的表达式、符号、有效值集合、边界条件及输入输出要求。自定义模块未提供的科学说明明确留缺，不生成假公式。
- **输入输出**：显示实例编译后的契约，包括轴、尺寸、样本数、dtype、科学含义和附加结果。尚未运行的估计与实际输出不能混称。

算法参数和显示参数分开；全局执行设置与实例覆盖分开。已有插件继续使用独立进程中的逐帧 prepare/process/close 契约，不因 GUI 更新而自动支持任意多维或时序算法。

## 数据截流导出

把“数据截流导出”放在需要检查的阶段之后：

```text
来源 → ROI 裁剪 → 浮点增益 → 数据截流导出 → 后续算法 → 最终结果
                              └→ 所在位置的完整上游输出
```

该模块获取直接前序输出，主路原样继续。名称用于区分不同截取位置；可选择交付到数据预览、文件或两者。导出保留真实的序列轴、空间 / 通道轴和数值类型。

| 形式 | 用途与约束 |
| --- | --- |
| 数据预览 | 正式完成的类型化输出进入工作区，可以明确选为下一流程输入 |
| 类型化数据集 | 一起保存完整数值、逐样本来源、契约和交付记录 |
| NPY | 保存完整数值数组；完整来源另在交付记录和引用文件中 |
| CSV | 适用于标量或受限大小的向量，不能把图像暗中压成统计值 |
| TIFF | 适用于具有 Y/X 空间轴的数据，保留数值和明确的轴信息 |

试算交付带有临时标记，不能作为正式来源晋级。侧输出失败、任务取消或源数据在运行中变化时，不发布可继续处理的完整数据集。原始来源不改写，每次运行使用独立输出目录。

## 提取和统计

点、线、截面、区域归约与分布结果区分两种用途：

- **旁路采集**：得到附加结果，后续模块继续接收原主路数据。
- **替换主路**：后续模块接收提取后的数据，重新校验形状和科学含义。

T 是时间样本，Q 是关联延迟；Q 信号不当作时间序列。直线位置使用 R，分布使用明确的箱轴，不把它们伪装成颜色或图像。

结果工具内可切换“沿样本 / 延迟轴”与“当前截面 / 分量”。R 使用真实剖面像素距离，分布使用固定箱中心；当前截面按指定样本精确读取，显示分量过多时明确抽样。静态 N 记录直接显示分量，不伪造时间轴。完整数值、CSV 与图形导出保留在结果工具中。

序列统计扫描其直接上游的完整 T 序列，产生均值、方差、计数及固定尺度，主路保持原数据。需要数值归一时，再接“固定尺度归一”。前置时间编辑和 ROI 会改变统计对象；普通播放不会重新扫描统计。

## 参数与结果传递

受支持的目标参数可以引用前序实例的明确参数或具名结果端口。引用是结构化数据，不执行任意 Python 表达式；不能向后引用或形成环。

例如固定尺度归一的 scale 可引用前序序列统计的 scale：

```json
{"scale": {"ref": {"node_id": "统计实例ID", "port": "scale"}}}
```

删除、停用或重排提供方后，依赖会重新校验。引用值和提供方的实际上游进入运行来源及数值指纹；窗口状态不参与。图像或任意数组不能未经类型检查直接当作标量参数。

## 科学含义与旧项目

W、τ、步长按关联模块直接收到的编辑后样本计数，保存真实配对时差。支持负、零和正延迟，不假定曲线对称；固定 τ 图与 τ 扫描使用独立目录入口、相同关联内核。

区域强度信号的 g² 与像素 g² 的空间平均是不同操作：前者先做区域归约再关联，后者先关联再归约。界面和结果记录保留这个顺序。

打开旧项目时，建立可编辑迁移副本：

- 原 ROI 像素模式映射为裁剪；归约模式映射为“裁剪 → 区域归约”，保留旧输出 ID 和有效像素规则。
- 原统计映射为“序列统计 → 固定尺度归一”，保留 none 时的 float64 转换及固定 RMS 回退规则。
- 原关联按图 / 曲线映射为两个明确入口，保留窗口、延迟、中心和输出轴。

已经完成的旧结果仍按原记录读取，不重新解释或覆盖。项目文件是长期保存入口；浏览器草稿和维护会话快照不能代替项目文件。
