# 0.5.0 统一算法模块与预览修复

本版落实 [工作指南](../AGENTS.md) 的算法模块化原则：模式提供预设和显示布局，算法属于统一模块目录。视频预览与数据处理继续共享来源、实际帧位置、ROI 和结果记录。

## 使用方式

分幅布局取消原来的五段编号页面。右侧只有一条实际执行的模块链，点击模块的“编辑此模块参数”打开该实例的专用交互；普通图像算法直接在模块内修改参数。“范围 / ROI / 设备”和“结果 / 导出”是工作台操作。

- 模块库可选择插入位置。所有模块均支持新增、删除、复制、启停和拖动排序，箭头提供相同操作。
- 每个实例独立保存标识、参数、版本和插件指纹。重复模块按出现顺序实际执行。
- 通用布局和分幅布局使用相同目录。可将分幅流程复制到通用布局，保留算法顺序、参数和精确帧运行上下文。
- 原始帧读取独立于关联参数验证。窗口为偶数、延迟越界、流程暂时缺少必要模块时，仍可查看、定位和播放原始帧；流程预览和运行显示具体错误。
- 更新后刷新浏览器即可加载新界面。静态资源要求重新验证，旧版草稿自动迁移，现代空流程保留为空。

## 模块与连接

| 模块 | 输入 → 输出 | 主要数值行为 |
| --- | --- | --- |
| 强度变换 | 单幅 / 双路 / 系数图 → 同网格 | 原有 dtype 保持策略，整数会舍入和截断 |
| 均值滤波 | 同上 | 原有有限值检查与反射边界，保持 dtype |
| 阈值分割 | 同上 → 标签 | 明确输出标签；标签不能隐式用于光强关联 |
| 线性缩放与偏置 | 同上 → 浮点 | `gain × x + offset`，不截断 |
| 空间高斯平滑 | 同上 → 浮点 | 可分离高斯核，复制边界、有限权重归一，原无效位置保持无效 |
| 强度曲线 | 同上 → 浮点 | 固定尺度的原值、线性、平方根、平方、幂和对数，不逐帧拉伸 |
| 强度校准 / LUT | 单幅 → 单幅 | 固定曲线或单调 LUT、左右暗场偏置、坏点及饱和排除 |
| 双幅划分与固定配准 | 单幅 → 对齐双路 | 中线、左右有效区、固定平移、镜像、最近邻或显式双线性采样 |
| 选择幅面 | 对齐双路 → 单幅 | 选择左路或右路，继续普通图像处理 |
| 全源均值与固定尺度 | 对齐双路 → 双路与统计量 | 全源 Welford 均值、方差和可选固定 RMS |
| 标准二阶互关联 | 对齐双路 / 双路与统计量 → 系数图 | 固定 τ 图或固定中心的双向 τ 曲线 |

逐帧算法在对齐双路上可选择“左路”“右路”或“双路”；结构和时序模块作用于完整输入。连接不兼容时提示调整位置，不静默重排或添加模块。例如，配准后可接高斯滤波，再接关联；配准后选择右幅，也可继续单幅处理。统计量后须接关联才能继续逐帧系数后处理。

强度校准可删除或重复。单幅校准若没有后续分幅中线，左右偏置必须相同。相邻校准与配准仍保证 LUT 在插值前作用于原始整数码值；重复 LUT 也必须满足各次实际输入为其覆盖的整数码值，不能把浮点强度暗中转成码值。

## 删除模块的实际行为

- 删除校准：使用进入分幅模块的原值，不在后台补入 LUT、暗场或归一化。
- 删除全源统计：跳过背景全序列扫描。关联直接累积局部强度，仍计算 `g² = ⟨LR⟩ / (⟨L⟩⟨R⟩)`；任务记录显示统计范围 `none`。只为实际读取的帧记录时间，不根据平均帧率填补时间。
- 删除关联：可保留全源统计任务，或添加“选择幅面”转为逐帧图像流程。只剩双路且没有终端模块时，明确提示补充幅面选择或关联。
- 清空流程：现代流程按原始图像直通处理。0.4.x 未声明新工作流版本的空列表继续按旧配置恢复，避免历史结果含义变化。

## 结果、扩展和边界

数据和结果仍使用独立视窗。系数后处理标记为 `processed_g2`，保存完整后处理链、值类型和变换后的参考值；原无效关联样本保持 NaN，标签后处理也不把无效样本改为有效零。处理后的数值与标准 g² 必须通过运行记录区分。

通用结果保存完整模块记录、几何映射、参数与实现文件摘要；分幅结果保存上游模块和每个校准实例的 LUT 指纹 / 快照，历史涨落检查使用快照。缓存依据实际上游流程建立指纹，修改关联之后的系数后处理不会重复拟合背景。

本地逐帧 Python 插件通过同一个注册入口接入两个布局，沿用 `prepare / process / close` 契约，在工作进程中执行。通用布局出现统计或关联模块时，由模块类型选择时序执行器，不依赖当前界面模式。外部时序 / 整体插件仍需执行器适配，当前不能将其伪装成逐帧插件。

CPU 完整可用，关联的 CuPy / CUDA 后端可选；逐帧模块使用自身声明的设备。τ 曲线仍与固定 τ 图独立运行。曲线任务的空间平滑需位于关联之前，关联之后的任意逐帧插件暂不用于点 / ROI 曲线，以免把缺少空间上下文的标量当成完整图像；系数图允许此类后处理。
